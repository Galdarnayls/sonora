# Sonora — офлайн-плеер для своей музыки

Сайт-приложение (PWA): ставится на ПК и телефон как обычное приложение и работает без интернета.
Музыка хранится внутри приложения на самом устройстве — никуда не загружается.

---

## 📱 Как выложить на GitHub и открыть на телефоне (пошагово)

Ничего устанавливать на компьютер не нужно — всё делается в браузере.

### Шаг 1. Зарегистрируйтесь на GitHub
1. Откройте https://github.com и нажмите **Sign up**.
2. Введите почту, придумайте пароль и **имя пользователя** (username). Запомните его — оно будет в адресе сайта.
3. Подтвердите почту.

### Шаг 2. Создайте репозиторий (папку для сайта)
1. Справа вверху нажмите **+** → **New repository**.
2. **Repository name:** `sonora` (можно другое, только латиница, без пробелов).
3. Выберите **Public** (бесплатный сайт GitHub Pages работает с публичными репозиториями).
   Вашу музыку там никто не увидит — в репозитории только код приложения.
4. Галочки ниже не ставьте. Нажмите **Create repository**.

### Шаг 3. Загрузите файлы
1. На странице нового репозитория нажмите ссылку **uploading an existing file**.
2. Откройте на компьютере папку проекта `copy of spotify` и перетащите в окно браузера **эти файлы и папку**:
   - `index.html`
   - `styles.css`
   - `app.js`
   - `sw.js`
   - `manifest.webmanifest`
   - `README.md`
   - папку `icons` (целиком, вместе с файлами внутри)

   Папку `.claude` загружать **не нужно**.
3. Подождите, пока все файлы появятся в списке (в папке `icons` их должно быть 5).
4. Внизу нажмите зелёную кнопку **Commit changes**.

### Шаг 4. Включите сайт (GitHub Pages)
1. В репозитории откройте вкладку **Settings** (шестерёнка вверху).
2. Слева выберите **Pages**.
3. В разделе **Build and deployment** → **Source** выберите **Deploy from a branch**.
4. В **Branch** выберите `main` и папку `/ (root)`, нажмите **Save**.
5. Подождите 1–2 минуты и обновите страницу — вверху появится ссылка вида:

   **`https://ВАШ-ЛОГИН.github.io/sonora/`**

   Это и есть адрес вашего плеера.

### Шаг 5. Установите на телефон
**Android (Chrome):**
1. Откройте ссылку в Chrome.
2. Меню **⋮** → **Установить приложение** (или «Добавить на главный экран»).
3. На рабочем столе появится иконка Sonora.

**iPhone (только Safari):**
1. Откройте ссылку в Safari.
2. Кнопка **«Поделиться»** (квадрат со стрелкой) → **«На экран „Домой“»** → **Добавить**.
3. ⚠️ Регистрируйтесь и добавляйте музыку уже **в установленном приложении** (с иконки), а не во вкладке Safari — у них разная память.

**Компьютер (Chrome / Edge):** откройте ссылку → значок установки в адресной строке → **Установить**.

### Шаг 6. Пользуйтесь
1. Откройте приложение → **создайте аккаунт** (имя и пароль).
2. Нажмите **«Добавить музыку»** → выберите свои аудиофайлы (на телефоне — из «Файлов» / «Загрузок»).
3. Всё, можно слушать без интернета. Для машины — **Настройки → Режим «Авто»**.

### Поделиться с другом
Просто отправьте ему ссылку `https://ВАШ-ЛОГИН.github.io/sonora/`.
У друга на его телефоне будет **своя отдельная медиатека** — ваша музыка и плейлисты ему не видны и наоборот.
Если вы пользуетесь одним устройством вдвоём — у каждого свой аккаунт со своим паролем.

### Как обновить сайт после изменений
1. В репозитории нажмите **Add file → Upload files**, перетащите изменённые файлы, **Commit changes**.
2. Через 1–2 минуты приложение на телефоне само подхватит новую версию при следующем запуске с интернетом.

## Важно знать
- **Аккаунты локальные.** Они хранятся на устройстве и разделяют медиатеки разных людей. Это не облачный вход: зайти в свой аккаунт с другого телефона нельзя, там нужно добавить музыку заново.
- **Если забыли пароль** — восстановить нельзя (пароль нигде не хранится, только его хэш). Можно создать новый аккаунт.
- Чтобы браузер не удалил музыку при нехватке места: **Настройки → «Защитить от автоочистки»**. Установленное приложение защищено лучше, чем вкладка браузера.

## Возможности
- Медиатека: все треки, любимые, плейлисты, исполнители, альбомы, поиск
- Чтение тегов MP3 (название, исполнитель, альбом, обложка; в т.ч. русские теги в cp1251)
- Перемешивание, повтор, очередь, «воспроизвести далее»
- Режим «Авто»: огромные кнопки, экран не гаснет, свайпы по обложке
- Кнопки на руле / Bluetooth / экран блокировки
- Импорт файлов и целых папок, drag & drop на ПК
- Несколько аккаунтов на одном устройстве, у каждого своя музыка

## Запуск на компьютере для разработки
```
python -m http.server 5173
```
Затем откройте http://localhost:5173.

После изменения кода увеличьте версию `CACHE` в `sw.js`.
